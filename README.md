# Независимое портфолио Юстины

Этот вариант сохраняет TanStack Start, страницы, RU/EN и 3D-карточку.
Фото и модели находятся в public/media, а не в хранилище Lovable.
media-manifest.json содержит размер и SHA-256 каждого файла.
Шрифты пока загружаются с Google Fonts; при их недоступности используются системные.

## Публикация на Cloudflare Pages
1. Создай новый закрытый репозиторий GitHub на своём основном аккаунте и загрузи сюда содержимое этой папки.
2. В Cloudflare открой Workers & Pages → Create → Pages → Connect to Git.
3. Выбери репозиторий. Команда сборки: bun install && bun run build.
4. Папка результата: dist/client. Используй актуальную стабильную версию Bun.
5. После публикации проверь главную, /cases, RU/EN, фотографии и вращение карточки.
6. Только после проверки подключи купленный домен в Custom domains и следуй инструкциям Cloudflare.
7. Не выключай прежний сайт до проверки нового адреса.

## Домен и сохранность
Покупай домен на своём основном аккаунте у отдельного регистратора.
Включи автопродление и двухфакторную защиту; проверь, что платёжный способ работает.
Сохрани эту папку отдельно от GitHub. Код, фото и модели нужны для восстановления вместе.
GitHub хранит код; Cloudflare Pages показывает сайт. Ни один сервис не гарантирует отсутствие всех сбоев.

## Локальная проверка
Установи Bun, затем выполни bun install и bun run build.
Не публикуй dist/server: сайт размещается как готовые страницы из dist/client.
